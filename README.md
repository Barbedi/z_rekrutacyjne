# Zadanie rekrutacyjne — adRespect

Zadanie polegało na odwzorowaniu strony internetowej na podstawie szkieletu z Figmy. Strona została zbudowana w oparciu o Tailwind CSS.

## Demo

[Demo](https://z-rekrutacyjne.vercel.app/)

## Stack technologiczny

- **Framework:** React
- **Stylowanie:** Tailwind CSS
- **Język:** TypeScript
- **Inne biblioteki:** Font Awesome, react-masonry-css, yet-another-react-lightbox

## Zaimplementowane funkcjonalności

- [x] Responsywny layout (mobile / tablet / desktop)
- [x] Rozsuwany search bar 
- [x] Sekcja hero ze sliderem
- [x] Animacje hover/transition na przyciskach i kartach
- [x] Galeria zdjęć oparta o bibliotekę Masonry (react-masonry-css) z lightboxem (yet-another-react-lightbox)
- [X] Nawigacja mobilna (hamburger menu)
